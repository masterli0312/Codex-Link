# Codex Link 1.0.2：界面与验证记录

基于 1.0.1 整合对话修复、按需同步、Cloud 管理及界面调整。版本为 **1.0.2 / versionCode 36**。

## 界面规范

- Material 3 与系统字体，主要页面边距 20dp，操作区域至少 48dp。
- 概览、账号详情与设置采用统一的中性背景、区块间距及细线图标，减少重复说明与装饰。
- 回复正文 17sp、1.2 倍行高及 6dp 额外行距；对话过程条目与本地轮次之间留白 24dp。Cloud 复用同一正文和过程组件。
- 复制图标仅在回复完成后显示，图案 18dp、触控区域 48dp；计时标签独立更新，不带动整段正文刷新。
- 运行时显示「已处理 × 秒」，超过一分钟显示「已处理 × 分 × 秒」；完成后显示用时及可展开的过程。
- 概览的刷新反馈放进卡片右下角更新时间位置，额度图示保持 82dp，不因更新状态改变尺寸。
- 桌面图标为居中的白底蓝紫标志；通知卡片复用应用图案，标准 Android 状态栏使用单色轮廓。

## 对话与操作

- 打开与同步校验真实线程、轮次和来源；旧任务结果不能验证或替换当前内容。同轮次较短响应保留更完整的内容，并解除首次加载等待。
- 首次加载使用静态灰色占位，无持续顶部加载线；流式 Markdown 内容没有变化时不重新排版。
- 引导和状态请求不再继承监听参数。执行中附件校验目标轮次；手机只在匹配的成功回执后移除对应待处理消息。
- 引导回执使用电脑独立发送通道和手机独立订阅，避免大段正文上传或下载阻塞确认。失败保留草稿，不自动重发未知结果。
- 对话按需同步，未选中的电脑对话仍接收任务完成提醒，不自动导入其完整历史。
- 左滑提供置顶、重命名、归档；归档确认、恢复及远程问题选项都校验对应请求身份。
- 草稿最多 10 个附件，保留预览与单独删除；生成文件可下载，PDF 内置预览，Office 文件由手机查看应用打开。
- Cloud 接入更早消息分页、重命名、归档列表及恢复。历史缓存有上限；完整环境发布、普通云对话、附件及后台通知的限制见 [Cloud 文档](cloud-environments.md)。
