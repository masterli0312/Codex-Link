# 电脑连接、任务提醒与远程对话（Codex Link 1.0.0）

**首次必须与自己的 Windows 电脑配对。** 仅安装手机 App 或登录 ChatGPT 不会收到电脑任务事件。每台电脑单独配对，私人 ZIP 不能公开分享。

**中国大陆用户接收任务提醒本身不需要 VPN 或 Google Play Services**，但手机和电脑必须能访问所选通知服务。额度读取、账号授权、自动激活与 Cloud 仍需访问 OpenAI。

## 首次安装与升级

1. 在「设置 → 电脑连接与同步」开启任务完成提醒，授予通知和后台运行权限。
2. 需要阅读和续聊时，开启正文同步与手机继续 Codex 对话；通知名称/回复预览单独选择。
3. 分享电脑安装包，传到自己的 Windows 电脑，解压并双击 `setup.cmd`。
4. 检查配对测试消息，按提示重启 Codex。需要与桌面继续同一线程时，启用下方共享连接。
5. 在「对话」读取电脑列表，打开已有对话或选择电脑和项目新建。

基础通知需要 Node.js 18+；双端共享需要 Node.js 22+，推荐当前 LTS。安装器查找已有运行时，并用 Windows .NET Framework 编译器生成无控制台启动器，保留原 Codex 回调；相关依赖缺失时会提示，不需要保持终端开启。

**升级至 Codex Link 1.0.0 后重新导出 ZIP、运行 `setup.cmd` 并按提示重启 Codex。** 开关正文同步或远程控制后也需更新电脑组件，使两端配置一致。只升级 APK 不会替换电脑代码。

## 任务通知

- 官方完成回调与本地明确完成事件补查发送本轮结束消息，后台重试去重；不能由日志推断所有客户端的任务完成。
- 可选显示真实对话标题及最后回复摘要，点击进入对应对话。预览默认关闭，锁屏公开通知使用通用提示。
- 正文同步关闭时只传必要事件元数据。开启后传可见文字的加密内容，不传 OpenAI 登录凭据、认证文件或隐藏推理。
- 任务结束不代表任务成功。电脑离线、系统停止 App、服务缓存过期和网络问题都可能影响送达。

## 双向对话

手机使用配对电脑的 Codex 认证与 Provider 配置，与概览中的额度账号无关。电脑需开机、用户已登录并能访问模型服务和中继；手机需能访问中继。

- 支持新建、续聊、搜索、重命名、归档/恢复和手机本地置顶。新建选择电脑与真实项目，也可选择无项目；在普通输入框发送后才创建任务。
- 模型和思考强度来自电脑实际目录，执行前校验。不添加不支持的强度或插件。
- 停止生成只针对当前任务。审批与补充问题绑定电脑、线程、轮次和交互 ID，必须明确答复；不自动批准。
- 执行中可「调整当前任务」，通过官方 `turn/steer` 匹配当前轮次；明确选择「完成后发送」才排队。附件保留给下一条支持附件的普通消息。
- 同一对话在两端使用，一轮只启动一次；不让重复点击启动重叠任务。电脑占用的线程需要共享模式才能继续。
- 命令执行、文件修改与插件显示紧凑条目，可展开看详细记录；未知工具来源不猜测。
- 支持多选图片/文件，合计最多三项。点击缩略图预览，X 删除；格式和大小不支持时给出提示。
- 系统语音转文字不可用时可下载 SenseVoice INT8 离线模型约240 MB。本地识别不保存或上传音频，结果仅进入草稿，不自动发送。系统语音服务的数据处理由所选服务决定。

### 历史、图片与缓存

正文使用官方 `full` 历史分页，每次读取近期轮次，可加载更早消息；不把摘要当成完整历史。每个对话文字最多500条、总计1 MB，操作摘要最多40条、64 KiB，达到上限会提示；手机缓存最多保留50个对话。

电脑可读取的本地、内嵌、生成或工作目录图片使用加密传输，单张最多8 MiB。手机展示紧凑缩略图，点击看大图，最多三张并发获取、有限重试并缓存；仅有外部网址、不可解析的文件 ID 或已删除源文件时不伪造图片。加密附件受中继容量和有效期影响，公共服务附件通常约3小时有效，以实际返回为准。

旧通知、延迟下载和旧任务不能覆盖较新的原生正文。打开最近有效缓存可直接展示，过期在线缓存先确认原生内容；离线及归档缓存可读。阅读历史时不强制滚到底，生成中的回复隐藏复制图标，完成后显示。状态面板先展示当前对话缓存再后台更新，不每次清空重载。

### 双端共享连接

默认独立 stdio 连接不能写入被桌面独占的对话。共享模式让兼容的 Codex Desktop 和手机组件使用同一个本机 app-server；只监听 `127.0.0.1`，不开放互联网控制端口。

在手机开启远程对话并更新电脑组件后，在 PowerShell 执行：

```powershell
$codexUsageHome = if ($env:CODEX_HOME) { $env:CODEX_HOME } else { Join-Path $env:USERPROFILE '.codex' }
& (Join-Path $codexUsageHome 'codex-usage-notifications/Enable-SharedConversations.ps1')
```

按脚本提示关闭并从其配置的入口重新启动 Codex。要求 Node.js 22+ 和支持共享 WebSocket 入口的 Codex Desktop。此前已在桌面与手机同一真实线程验证双向续聊；这不是官方承诺长期稳定的桌面设置，升级后可能需要复查。脚本发现其他原生连接配置时停止，不覆盖无关连接。

停用共享连接：

```powershell
& (Join-Path $codexUsageHome 'codex-usage-notifications/Enable-SharedConversations.ps1') -Disable
```

按提示重新登录 Windows 或清理终端中遗留的共享环境变量，再正常启动 Codex。原对话不转换成分支、不删除锁文件或凭据。

## 持续对话建议使用独立中继

公共 `ntfy.sh` 存在每日消息额度、发送频率及附件限制。HTTP 429、错误码 `42908` 表示每日发送额度耗尽：订阅可在线，但无法发布回复或连接确认。反复重装、切换模型不会消除限额。

可部署兼容的独立 [ntfy](https://github.com/binwiederhier/ntfy) HTTPS 服务，使用可信证书、持久缓存和适合流式对话的额度。反向代理关闭响应缓冲、读超时大于心跳间隔；限制允许访问的配对主题，配置附件容量与有效期。服务器只转发密文与必要元数据，不保存 OpenAI 登录凭据。

在高级通知服务地址中**保留原主题，仅更换 HTTPS 服务器地址**，可保留对应配对密钥、草稿和缓存。随后重新导出安装 ZIP 更新电脑，使两端使用同一服务。其他电脑配对不自动迁移。更换主题会清除对应配对缓存；旧附件仍依赖原服务器有效期。

共享模式订阅原生事件，手机按稳定消息 ID 合并增量。独立中继的手机任务合并间隔为300毫秒，公共服务为1秒以控制消息量；这些不是屏幕显示延迟保证。断线后恢复完整状态，不重放任务。网络、Provider 和渲染仍影响实际速度。

## 多台电脑与连接状态

- 每台电脑用「添加电脑」生成独立配对并导出自己的 ZIP，不将同一 ZIP 作为多个独立电脑配置。
- 草稿、模型、历史与通知按配对和电脑身份隔离。项目名称来自真实电脑；电脑名字不是固定功能名。
- 连接状态以电脑实际响应判断，不能仅凭中继在线显示电脑在线。网络短暂中断自动恢复，离线时保留草稿和缓存。
- 不确定任务保留确认状态，查询同一请求，不自动重新执行。120秒有效期用于防止旧请求被重放，不代表任务仅可运行120秒。
- 解除配对移除接收入口和密钥，已保存历史可离线阅读；晚到响应不恢复配对，重新连接需导出新包。

## 安全边界与卸载

- 正文、远程请求和附件采用独立配对密钥加密，校验请求身份、方向和时效，重发同一编号不重复启动任务。
- 手机密钥、草稿和缓存由 Android Keystore 加密；电脑组件保存其必要配对配置与加密传输内容。电脑已有的 Codex 文件权限保持原样。
- 中继仍能观察 IP、时间、主题和密文大小；随机主题不等于访问控制。配对 ZIP、主题和密钥不要公开。
- 不开放任意远程 RPC；目录来自电脑真实项目，命令与文件操作受所选权限策略控制。未支持的交互类型转到电脑处理。
- 关闭手机功能并更新电脑组件才能停止电脑对应内容发送。删除手机缓存不删除电脑原对话。

卸载电脑组件时，在解压的安装目录运行 `Install.ps1 -Uninstall`（按系统要求在 PowerShell 执行），恢复其串接的原回调并停止后台组件。使用共享模式时先停用共享连接，再卸载。无需删除 Codex 原对话或登录文件。

## 常见问题

| 现象 | 检查方法 |
| --- | --- |
| 手机登录后没有任务通知 | 先完成电脑配对，确认已运行新的 `setup.cmd`，允许通知和后台运行。 |
| 对话可读但不能发 | 开启远程对话并更新电脑组件；桌面占用的线程启用共享连接。 |
| 电脑在线但收不到回复 | 检查通知服务日额度、网络与组件状态，区分中继连通和电脑响应。 |
| 锁屏收不到通知 | 检查通知权限、省电、后台运行与强行停止状态；缓存补取受服务期限限制。 |
| 额度或激活失败但任务通知正常 | 两条网络通道不同，确认手机能访问 OpenAI，必要时切换可用节点。 |
| 模型或插件没有某选项 | 以电脑实际能力目录为准，不支持的选项无法通过手机强行启用。 |

Cloud 是独立实验性功能，范围见 [Cloud 环境接入](cloud-environments.md)，不要将电脑对话功能的验证范围直接套用到 Cloud。
